Summary: First release that make-usb-kit.py accepts: it ships hmi.service and the polkit rule. Uses the one fixed
address per port network layout instead of br0, and the HMI changes its network settings without sudo. Also includes
the alarm, data log and control changes since v2.0.10.

Built by tools/create_release.sh: HMI cross-compiled with scripts/build-cross.sh, control and iot with ESP-IDF 5.4.3
and the repo dev signing keys. Not yet run on hardware.
