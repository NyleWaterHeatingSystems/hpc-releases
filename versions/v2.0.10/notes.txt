Rebuilt on 2026-11-04 from tag v2.0.10, after the fact. The original v2.0.10 binaries were not kept, so a unit running v2.0.10 has different files. hmi was built on an ED-HMI with GCC 12.2 (Bookworm); control and iot with ESP-IDF 5.4.3 and the repo dev signing keys. Source commit is exact.

Not usable with make-usb-kit.py: this commit has no hmi.service or polkit rule, and this app uses the older br0
network layout, which the current provisioner replaces. Kept as an archive of the release.
