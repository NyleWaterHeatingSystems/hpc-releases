v2.0.17 (2026-11-24)

Supported units: E180 and C90A build; not yet tested on hardware.

Summary: The setpoint log's columns now follow SPlog Table V2000 (renamed, reordered, some removed), so
anything that reads those CSVs needs updating. The HMI sends Holding to the MCP at 400120, and SP/MP now uses
the C-series PLC encoding (1 = singlepass). Condenser flow uses a linear calibration, filtered to the same
time constant as before. HMI Communication Lost has a startup grace period on both sides. A Firmware Version
Mismatch warning is added. While disconnected, the HMI shows its own clock and the factory password can be
entered; the daily passwords follow the local date. HMI variable table changed: regenerate hpc-gateway's
conf with --remap. Flash control, iot and the HMI.
