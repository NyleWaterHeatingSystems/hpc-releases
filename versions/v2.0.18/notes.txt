v2.0.18 (2026-11-24)

Supported units: E180 and C90A build; not yet tested on hardware.

Summary: One FAT32 USB stick now does setup, updates and logging, each in its own folder: HPC_SETUP/ (the
kit), hpc-releases/ (a copy of this checkout) and HPC_LOGS/. USB updates read hpc-releases/, falling back to
releases/. Each release now ships its USB updater, which a USB update installs with the app. Provisioning a
FAT32 drive on the Diagnostic page resets only HPC_LOGS; other drives are still erased. A panel set up with
an older kit keeps an updater that reads only releases/: run this release's kit on it once (HOWTO 3.2).
Control and iot are unchanged from v2.0.17 apart from the version; flash them so the versions match.
